# Contributing to TaskFlow

Thank you for your interest in contributing to **TaskFlow**! We welcome contributions to make TaskFlow the best open-source, offline-first productivity platform.

---

## How Can I Contribute?

### 1. Reporting Bugs
- Search existing [Issues](https://github.com/mohammed-m-alhaj/taskflow/issues) before submitting a new one.
- Use our **Bug Report** template with steps to reproduce, expected behavior, and error logs.

### 2. Suggesting Features
- Open a **Feature Request** describing the use case and proposed implementation.

### 3. Pull Request Guidelines
1. **Fork** the repository.
2. Create your feature branch:
   `ash
   git checkout -b feature/amazing-feature
   `
3. Verify your changes pass all tests and lint checks:
   - Backend: cd Backend && python test_backend.py
   - Flutter: lutter test and lutter analyze
4. Commit your changes with clear, descriptive commit messages:
   `ash
   git commit -m "feat: add support for recurrent task scheduling"
   `
5. Push to your branch and submit a **Pull Request** targeting main.
